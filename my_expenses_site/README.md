# Мои расходы — проект сайта

## Файлы
- `index.html` — структура страниц и элементы интерфейса.
- `styles.css` — оформление, адаптивность и темы.
- `app.js` — логика приложения, SQLite через sql.js, профили, расходы, фильтры, экспорт.

## Запуск
Откройте `index.html` в современном браузере с подключением к интернету (библиотека sql.js и шрифт загружаются с CDN).
Если браузер блокирует криптографические функции при открытии через `file://`, запустите локальный сервер:
`python -m http.server 8000`
Затем откройте `http://localhost:8000`.

## Важно
Это учебный прототип: SQLite-база хранится в localStorage браузера и не синхронизируется между устройствами. Парольная схема здесь не заменяет серверную аутентификацию. Для полноценной сдачи проекта с настоящей серверной БД следующий этап — backend (например, PHP + MySQL или Node.js + PostgreSQL).
